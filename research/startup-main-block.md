# Japanese startup main block

The cartridge entry chain reaches `0x1F3A`. This verified 52-byte block
performs the same hardware and WRAM initialization shape as Aka/Midori, but
calls the Ao-specific target `0x16C7` and loops at `0x1F66`. The exact ROM
identity, source, and report are hash-bound without publishing a standalone
ROM fragment. The candidate remains unverified.
