# Version Targets

This project tracks the following Pocket Monsters Ao / Pokémon Blue release families as separate reproducible build targets while sharing common source where byte-identical or structurally equivalent.

- JP — Pocket Monsters Ao
- EN — Pokémon Blue Version (USA/Europe)
- DE — Pokémon Blaue Edition
- FR — Pokémon Version Bleue
- IT — Pokémon Versione Blu
- ES — Pokémon Edición Azul

Version-specific differences should be isolated here or through clearly documented conditional build logic rather than duplicated unnecessarily.
